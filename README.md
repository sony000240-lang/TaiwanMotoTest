# 台灣機車筆試遊戲

以遊戲化方式練習台灣機車筆試的單頁網站。提供完整題庫、章節闖關、即時解析、錯題複習與限時模擬測驗；主要遊戲內容收錄在單一 `index.html`，不需安裝套件或建置即可在瀏覽器中執行。

> 本專案是練習工具，並非官方考試或主管機關服務。實際考試內容、規則與交通法規請以主管機關最新公告為準。

## 功能一覽

- **808 道練習題**：題目依三大主題整理，保留題庫來源題號、選項與解析。
- **原始圖題**：使用來源題庫中的 148 張標誌與手勢圖裁切圖，並隨單檔 HTML 內嵌，避免遊戲時還需下載圖檔。
- **闖關地圖與掌握度**：首頁顯示三大主題的答題進度與掌握情形。
- **遊戲化視覺**：鮮明配色、圓潤按鈕、機車吉祥物，以及答題與成績動畫。
- **多種練習模式**：全題庫快測、單元 10 題快測、單元總測驗、模擬測驗與錯題重練。
- **即時回饋**：一般練習作答後立即顯示正誤與解析，並提供答題動畫；答錯題目會加入錯題本。
- **成績與圖表**：回合結束後顯示成績、章節表現雷達圖與答題統計。
- **本機帳號**：可設定名稱、查看個人答題紀錄、新增與切換帳號，以及清除指定帳號紀錄。
- **行動裝置友善**：支援手機直向瀏覽；測驗期間會隱藏地圖、導覽和側欄資訊，減少干擾。

## 三大主題與題數

| 主題 | 題庫來源題號 | 題數 |
| --- | ---: | ---: |
| 正確觀念與態度 | 1–480 | 480 |
| 主動停讓文化 | 481–572 | 92 |
| 安全駕駛能力 | 573–808 | 236 |
| **合計** | **1–808** | **808** |

題庫另外依來源文件整理為 10 個子主題，包括貨物裝載、路口安全、轉彎、正確使用燈光、行駛中注意事項、大型車安全、禁止不當行為、行車檢查、平交道與特殊情境，以及事故預防及處理。題目畫面會以括號顯示來源題號，例如「(題號123)」。

## 遊戲模式

### 10 題快測

首頁提供從三大主題抽題的全題庫快測；闖關地圖上也可直接為個別單元開始 10 題快測。每題作答後立即提供正確答案與解析，可用來短時間複習。

### 單元總測驗

由章節選擇頁進入，測驗所選主題的完整題庫，題目順序會打亂。完成後可查看該回合成績與章節表現。

### 模擬測驗

- 每回合隨機抽取 50 題。
- 作答時間為 30 分鐘；時間到會自動交卷。
- 每題 2 分，85 分及格；因分數以 2 分為單位，至少答對 43 題（86 分）才會及格。
- 作答期間不顯示正確答案；答錯或未作答的題目會加入錯題本。
- 測驗進行中若要離開，網站會提醒可能放棄本回合。

### 錯題本

集中整理答錯題目，支援逐題重練或一次重練全部錯題。模擬測驗未作答的題目也會列入錯題本。

## 本機帳號與資料保存

首次使用時需設定一個顯示名稱。帳號不需要密碼，帳號與答題資料都儲存在目前瀏覽器的本機儲存空間（`localStorage`），不會自動上傳至伺服器，也不會在不同裝置或不同瀏覽器間同步。

帳號總覽可查看累積作答題數、星星、連續練習天數、錯題數與各主題掌握度。可以新增及切換本機帳號；每個帳號的紀錄互相分開。清除指定帳號紀錄前會先要求確認，測驗進行期間則不能切換帳號或清除紀錄。

若瀏覽器內已有舊版匿名紀錄，首次命名時會沿用該紀錄。請勿將本機帳號視為安全的身分驗證或備份機制。清除網站資料、重設瀏覽器或更換裝置可能導致紀錄無法復原；重要進度請自行保留備份。

## 執行方式

遊戲已部署至 [GitHub Pages](https://sony000240-lang.github.io/TaiwanMotoTest/)；專案原始碼公開存放於 [GitHub 儲存庫](https://github.com/sony000240-lang/TaiwanMotoTest)。如需在本機執行，可使用以下方式。

### 直接開啟

下載或複製專案後，可在檔案管理器中開啟根目錄的 `index.html`。題目資料與圖像已收錄在該檔案中。

### 使用本機 HTTP 伺服器（建議）

使用本機伺服器可讓瀏覽器以固定網址保存 `localStorage`，較適合持續記錄遊戲進度。專案不需要安裝 Node.js 套件或執行建置流程；只需安裝 Python 3：

```bash
git clone https://github.com/sony000240-lang/TaiwanMotoTest.git
cd TaiwanMotoTest
python3 -m http.server 8000
```

然後以瀏覽器開啟 <http://localhost:8000>。若使用 Windows 且 `python3` 指令不存在，可改用：

```powershell
py -m http.server 8000
```

在終端機按 `Ctrl+C` 可停止伺服器。即使沒有網路連線，仍可從本機伺服器使用已下載的專案檔案；GitHub 複製步驟本身則需要網路。

遊戲執行時以 `index.html` 為入口；`src/` 中的 JSON 檔案是方便維護與檢視的結構化資料，不是啟動網站時必須另外載入的資源。

## 開發與驗證

本專案目前採用原生 HTML、CSS 與 JavaScript，沒有建置工具或第三方執行期套件。修改後可直接重新載入 `index.html` 或本機伺服器頁面。提交前建議檢查：

```bash
# 檢查內嵌 JavaScript 語法
python3 - <<'PY'
from pathlib import Path
import re
html = Path('index.html').read_text(encoding='utf-8')
script = re.search(r'<script(?:\s[^>]*)?>([\s\S]*?)</script>', html)
if not script:
    raise SystemExit('找不到內嵌 script')
Path('/tmp/taiwan-moto-test.js').write_text(script.group(1), encoding='utf-8')
PY
node --check /tmp/taiwan-moto-test.js

# 檢查題庫 JSON 格式
python3 -m json.tool src/questions.json >/dev/null
python3 -m json.tool src/pdf-figure-map.json >/dev/null

git diff --check
```
